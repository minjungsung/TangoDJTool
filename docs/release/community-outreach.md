## Short usage introduction

Sharing a tango set-preparation tool that I am involved with: Tango DJ Studio.

You can try it at https://tangodjtool.vercel.app/ — add your recordings in Music, arrange tandas and cortinas in Set, then open Play to run the queue. Cortinas have start/end cues, and local recordings support entrance and endpoint fades. The example set uses official YouTube videos if you want to explore the workflow first.

Your imported recordings stay in this site's browser storage. Export JSON to back up the set structure and keep the original audio files. YouTube needs a connection, and its fades depend on the device. Preview uses the main output, so check it before a live session.

Feedback on the phone workflow and cortina preparation would be useful.

## Tutorial post

A quick way to prepare a practice tanda with Tango DJ Studio (a project I am involved with):

1. Open https://tangodjtool.vercel.app/ and add local recordings in Music.
2. In Set, create a tanda, select “Choose recordings for this group,” then Add the recordings in order.
3. Add a cortina and choose its start/end interval.
4. Load the set and use Play, Pause, and Next. Choose Fade in the playback options when needed; local audio is the reliable option for fades.
5. Export the set JSON before moving devices. It contains the order and metadata, so keep the audio and relink it on the destination device.

The app works with phone, tablet, and desktop layouts. YouTube examples are available for trying the organization workflow, with the provider's normal playback restrictions. This is a preparation and playback tool; rehearse the audio output before using it at an event.
