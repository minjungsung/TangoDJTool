Tango DJ Studio privacy policy

Effective date: October 16, 2026.

Tango DJ Studio prepares and plays tango sets. This policy applies to the website and its Android Trusted Web Activity.

Your music and workspace

Imported audio, recording metadata, groups, queues, and preferences are stored on your device in the browser's IndexedDB and local storage for this site. The app does not upload imported recordings or exported set files to an application backend. Exported JSON contains recording metadata and set structure, but not audio. You choose when to export or import it.

External services

Opening the website contacts its hosting provider, Vercel, which can process connection information such as IP address and request metadata. Google Fonts is requested for interface typography. Adding a YouTube link requests its public metadata; playing YouTube sources loads Google's official embedded player. These providers can receive network and device information and may use cookies or other storage under their own policies. Local audio is not sent to YouTube.

See Vercel's policy and Google's policy. This app has no application analytics SDK, advertising SDK, user accounts, or cross-device synchronization.

Android permissions and browser storage

The Android launcher uses internet access and a supported browser to display the website. File access is selected by you through the browser's file picker. It does not request microphone, contacts, location, or broad music-library access. Local workspace data belongs to the browser/site; uninstalling the launcher alone may leave that browser data intact.

Deletion and backups

Delete individual recordings from the library or clear this site's data in your browser settings to remove the stored workspace. Clearing storage can also remove imported audio and saved sets. Keep original recordings and export a backup first. Delete downloaded exports separately through your device's file manager.

Contact

For support or privacy questions, use the project support page. Do not include private recordings or personal information in public issue reports.
