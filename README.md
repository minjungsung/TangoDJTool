# Tango DJ Studio

A new tool for preparing and performing tango DJ sets.

This project is maintained independently from TangoDJ.

## Status

Repository initialized. The initial workflow and application platform are being defined.

## Product direction

Help tango DJs work with their music collections and prepare music for milongas.

Potential workflows to evaluate:

- Organize recordings by orchestra, singer, year, and dance style.
- Build tandas and place cortinas between them.
- Prepare and play a set with a queue and preview controls.

These are candidate workflows; the first version will focus on the selected priority.
